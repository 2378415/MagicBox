# 上机记录：2026-11-09 第一次烧录（LEFT / 部分重建固件）

## 1. 环境

| 项 | 值 |
|---|---|
| 目标 | LEFT 片（V3.2，设备侧），`VID_303A&PID_0009` |
| 端口 | 芯片原生 USB-Serial-JTAG：烧录前 `COM9`，烧录后重枚举为 `COM11` |
| 固件 | `app_left/build/makcu_left.bin`（253,792 B，含 `cmd_version` / `cmd_nop` / `cmd_move`） |
| 控制台 | UART0 + USB-Serial-JTAG 双路（决策 D14），本机只有原生 USB 可用 |
| 备份 | `work/hw_left_before_rebuild.bin`（4,194,304 B），与官方 `V3.2_LEFT.bin` 前 403,536 字节逐字节一致 |

## 2. 烧录

```
idf.py -p COM9 -b 921600 flash
... Hash of data verified.  Hard resetting with a watchdog...  Done
```

烧录后设备重枚举为 `COM11`（USB-Serial-JTAG 由新固件安装驱动后重新出现）。

## 3. 冒烟验证（`tools/flash_verify.py --port COM11`）

```
PASS version          reply=b'km.MAKCU\r\n>>> '
PASS version-prefix   reply=b'km.MAKCU\r\n>>> '
PASS move-echo        reply=b'km.move(10,5)\r\n>>> '
PASS silent-null      reply=b''
```

三条与原始固件实测完全一致（`version` 回包、前缀匹配、`move` 回显），
`silent()` 因为槽位未移植而保持静默，也符合预期。

## 4. 协议回归（`pytest verification/regress`，共 16 例）

```
8 failed, 7 passed, 1 xpassed
```

**通过（7）**

| 用例 | 说明 |
|---|---|
| `test_echo_replies[.km.version()]` | `cmd_version` |
| `test_echo_replies[.km.version]` | 前缀匹配 |
| `test_echo_replies[.km.move(10,5)]` | `cmd_move` 解析 + 回显 |
| `test_no_reply[.km.silent()]` | `<2` 参静默 |
| `test_no_reply[.km.silent(0)]` | 同上 |
| `test_no_reply[.km.silent(1)]` | 同上 |
| `test_no_reply[.km.foobar()]` | 查表未命中 → 零回应 |

**失败（8，全部是未移植的 handler，属预期）**

| 用例 | 缺失的 handler |
|---|---|
| `test_echo_replies[.km.catch_ml(1)]` | `cmd_catch_set`（0x0A） |
| `test_echo_replies[.km.silent(0,0)]` | `cmd_silent`（0x19） |
| `test_serial_query` | `cmd_serial`（0x1A） |
| `test_status_commands_are_answered` ×5（buttons()/buttons(1)/buttons(0)/left()/right()） | `cmd_buttons`（0x0C）、`cmd_button_click`（0x05） |

**xpass（1）**：`test_hidden_opcode_not_reachable` —— 本固件没有实现二进制帧路由器，
单字节帧自然没有回应，所以断言“意外”通过；判定仍标注为推断。

## 5. 回滚

```
esptool --chip esp32s3 --port COM11 --baud 921600 write_flash 0x0 work/hw_left_before_rebuild.bin
Wrote 4194304 bytes ... Hash of data verified.
```

回读整片核对：

```
restored vs backup: 4194304/4194304 = 100.0000%   identical: True
app ver: 1
```

回滚后设备重新枚举（`COM11`），但不再响应该端口的文本协议——与原厂固件的
控制口在 UART0/CH343 上一致，说明重建固件已被完全替换掉。

## 6. 结论

- T1（可编译可烧录可启动）在真机上成立；
- 三个 handler 的**协议面**与原厂字节级一致（回包字符串逐字节相同）；
- 运动面尚未移植，`move` 只回显不移动；
- 下一次上机建议带着 CH343（`COM8`）一起，才能同时验证 UART0 通路。
