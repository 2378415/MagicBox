# 上机记录：2026-11-09 第十二批（UART1 桥接 + 免按键烧录打通）

## 1. 本轮实现（`makcu_link` 从帧层升级成桥）

| 部分 | 内容 |
|---|---|
| 驱动/任务 | UART1 @921600，`uart_read_bytes` 逐字节喂流式解析器，独立任务 `km_link`（优先级 9） |
| 帧格式 | `5A <cmd> <len:u16> <payload>`（`uart1_link.md` §6 定稿布局） |
| `0xA0` EP0 隧道 | 计数并区分方向（`payload[0]==0x00` IN、`0xFF` OUT）；真正的 EP0 应答待 P5 |
| `0xA2` HID 数据块 | `payload[0]` 端点、`payload[1]` 会话、`payload[2]` 长度、`payload[4..]` 数据 → **按端点重组**（克隆描述符的原料） |
| `0xA3` / 未知 / 坏魔数 | 计数后丢弃 |
| 台架入口 | `mx.lb`（自环发帧）、`mx.lb0`（关自环）、`mx.ls`（七项计数）、`mx.dc <ep>`（回读重组结果） |

引脚仍是占位（`MAKCU_LINK_TX=17 / RX=18`，`-D` 可覆盖）——原厂那两个引脚常量静态恢复不出来。

## 2. 上机结果（79 例全绿）

```
78 passed, 1 xpassed, 0 failed   (73.6 s)
```

硬件自环证据：

```
mx.lb  -> 13                       # 9 字节负载 + 4 字节头确实写出
mx.ls  -> 4,0,0,0,4,0,0            # 4 帧、4 个 HID 块、无未知帧
mx.dc 1-> deadbeef11…              # 端点 1 的重组内容与发送端一致
```

覆盖链路：构帧 → UART 线上往返 → 解析 → 派发 → 分块重组。覆盖不到：EP0 隧道（需第二颗芯片 + 设备栈钩子）。

## 3. 抓到的两个真 bug

### 3.1 loopback 关得太早（首次 2 例失败的直接原因）

```c
set_loopback(true); uart_write_bytes(...); set_loopback(false);   // ← 错
```

`uart_write_bytes` 只是填 TX FIFO 就返回，字节还没移出时 loopback 被关掉，RX 一个字节都收不到
（当时 `mx.ls` 七项全 0）。修法：新增 `makcu_link_loopback_selftest()`——开 loopback → 发送 →
`uart_wait_tx_done()` → 等 20 ms → 保持开启，另给 `mx.lb0` 关闭。

### 3.2 `-Define` 被 PowerShell 拼成一条参数（这条最值钱）

构建日志里出现过：

```
MB_DEBUG_OPCODE:BOOL=ON,-DMB_HID_DEVICE=OFF      ← 整个当作一个 -D 传给 CMake
MB_HID_DEVICE:BOOL=ON                            ← 于是"控制台构建"一直都是 HID 构建
```

后果：好几轮所谓的"控制台构建"其实是 HID 构建，所以 USB-Serial-JTAG 的 CDC 一直不枚举、
必须按 BOOT 才能烧 —— **不是芯片的问题，是我的构建脚本的问题**。

修法：`build_app.ps1` 把 `-Define` 按逗号拆回多个参数。修完后 `CMakeCache.txt` 干净：

```
MB_DEBUG_OPCODE:BOOL=ON
MB_HID_DEVICE:BOOL=OFF
```

控制台构建随即恢复了 `VID_303A&PID_0009` 的 CDC（COM9）。

## 4. 意外的收获：以后**不用再按 BOOT**

`mx.dl` 把芯片送进 ROM 下载模式后，ROM 的加载器**同时监听 UART0**，而 UART0 正好挂在那根常插的
CH343（COM8）上。于是完整闭环可以全软件完成：

```
mx.dl（COM8 发一行）→ ROM banner: boot:0x2 (DOWNLOAD(USB/UART0))
esptool --port COM8 --before no_reset write_flash ...
```

本轮的回归烧录与回滚都是这样做的，全程没碰按键。脚本：`tools/reflash.ps1`
（`-Restore` 直接回写原厂镜像并回读校验）。
