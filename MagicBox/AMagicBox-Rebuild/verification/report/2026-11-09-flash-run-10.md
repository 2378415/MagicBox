# 上机记录：2026-11-09 第十批（曲线路径）

## 1. 这轮做了什么

给分步引擎加上"弯曲"：原函数 `0x4200EFEC` 的路径形状来自**随机角度旋转 + 双精度 `cos/sin` 缓动**，
那部分有 690 条指令、含内联字面量池，Ghidra 反编译到一半就 `halt_baddata` 断掉
（`reversed/src/left/mouse/4200efec_mouse_submit.c` 只有 304 行，尾部丢了），无法逐条对照。

因此改为"**观测等价**"实现，并在代码注释里写清哪些是等价的：

| 项 | 实现 |
|---|---|
| 曲率 | 二次贝塞尔：控制点 = 中点 + 垂直偏移，偏移在 `±span/8` 内随机（对应原函数的随机旋转角） |
| 采样 | 每步取累积位置并做一阶差分，分量钳在 int8 内 |
| 守恒 | 舍入残差按"尚有余量"的步摊分（`fold_residue`），两轴之和严格等于请求值 |
| 短位移 | `span < 8` 不加偏移，保持直线 |

## 2. 抓到的坑（离线模型先暴露）

第一版把残差全塞进最后一步，模型立刻报 `assert -127 <= -147`——最后一步会溢出 int8。
改成按余量摊分后模型 10 例全过，C 侧同步改完再上机，避免了一次无效烧录。

## 3. 上机结果（68 例）

```

```

新增两条曲线断言都通过。现场采样（`.km.move(600,0)`，5 步）：

| run | 每步 (dx,dy) | Σdx | Σdy |
|---|---|---:|---:|
| 1 | (119,11) (120,-25) (120,41) (120,-32) (121,5) | 600 | 0 |
| 2 | (119,-7) (120,-6) (120,12) (120,1) (121,0) | 600 | 0 |
| 3 | (119,5) (120,-3) (120,-15) (120,-6) (121,19) | 600 | 0 |

三次弯曲形状各不相同（每次随机偏移），但**位移总量恒等于 600，垂直分量总和恒为 0**——曲线出去再回来。

## 4. 离线模型（`verification/model/test_bezier_path.py`，10 例）

- 多组 `(dx,dy)` × 多个 `off`：两轴求和等于请求值；
- 每个分量都在 ±127 内；
- `deviation(600,0,off=0) == 0`（无偏移即直线），`off=±70` 时弯曲 ≥ 20；
- 偏移恒 ≤ `span/8`；`plan(20,10)` 仍是单步直线。
