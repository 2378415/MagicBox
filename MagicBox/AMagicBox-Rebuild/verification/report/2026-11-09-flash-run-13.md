## 2. 线上证据（`mx.dv` 实测）

```
init=1 mnt=0
dev : 12 01 00 02 00 00 00 40 6d 04 77 c0 00 01 01 02 03 01
cfg : 09 02 22 00 01 01 00 a0 32 | 09 04 00 00 01 03 01 02 00 |
      09 21 11 01 00 00 01 22 34 00 | 07 05 81 03 40 00 01
rep : 52 字节，首字节 05
```

逐字段核对全部自洽：

| 项 | 值 | 判断 |
|---|---|---|
| bLength / bDescriptorType | 18 / 01 | ✓ |
| bcdUSB | 0x0200 | ✓ |
| bMaxPacketSize0 | 64 | ✓ |
| VID:PID | **0x046D:0xC077** | ✓ 已换成 clone 身份 |
| bNumConfigurations | 1 | ✓ |
| wTotalLength | 34（= 9+9+9+7） | ✓ 与内置一致 |
| HID 类块声明长度 | 0x34 = 52 | ✓ 与 `rep=52` 一致 |
| 端点 | 0x81 interrupt, 64 字节, 1 ms | ✓ |

**结论：描述符侧（仓库 → 回调 → 交还主机）已经跑通且自洽。**

## 3. 这轮踩的三个坑

1. **`wTotalLength` 少算 HID 类块**：初版写的 `9+9+7=25`，漏了 9 字节 HID 描述符（应为 34）；
2. **运行时 `tud_disconnect/tud_connect` 不恢复枚举**：换完描述符立即重连，主机侧再也看不到设备；
3. **应用内 `esp_restart()` 之后 USB 也不回来**：软件复位不会拉低 D+，主机不重新枚举。因此克隆改为
   "写仓库 → 下一次真实复位（烧录或插拔）生效"，台架验证走 `-DMB_CLONE_FIXTURE` 开机装载。
