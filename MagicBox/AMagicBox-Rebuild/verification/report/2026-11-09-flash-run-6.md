## 1. 本轮移植

| handler | opcode | 原地址 | 语义 |
|---|---|---|---|
| `cmd_wheel` | 0x07 | `0x4200E358` | 单个带符号整数（多位数）→ 钳 int16 → 收窄 int8 → `wheel_submit`（`0x4200F96C`）→ **无条件回显**（空参也回） |
| `cmd_map_16` | 0x15 | `0x4200EA04` | 首值 `parse_int_or_char`；逗号后内联解析一位数字（0..0xFF）→ `map_entry_write16`（`desc+0x163`）→ 回显；首值为 0 则静默 |
| `cmd_map_entry` | 0x16 | `0x4200E624` | 两个 `parse_int_or_char`，**两者都非零**才 `map_entry_write`（`desc+0x63`）并回显，否则连回执都不发 |
| `cmd_dump_channels` | 0x17 | `0x4200DBB0` | 扫 0..255，三标志（`desc+0x269`/`desc+0x369`/`dev+0x636`）全非零则 `"%d"` 回该索引，否则回字面量 `"0"` |
| `cmd_channel_toggle` | 0x18 | `0x4200E56C` | `idx = parse_int_or_char`；`idx>255` 或 `desc[idx+0x369]==0` → 只回显；否则逗号后字符写 `desc[idx+0x269]` 并置/清 `0x3FC99FA3`（`makcu_resend_flag`） |
