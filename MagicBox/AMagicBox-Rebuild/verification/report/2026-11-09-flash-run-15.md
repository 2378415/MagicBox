# 上机记录：2026-11-09 第十五批（JTAG / openocd 打通）

> 目的：确认 `openocd-esp32` + 内置 USB-JTAG 能不能用。这是 D9/D10/R2 里
> “隐藏 opcode 只有 openocd 单步才能实测”、以及接下来 EP0 隧道/`0xA2` 联调的**前置能力**。
> 结论：**能用**，jtag tap、双核 examine、gdb attach、活体内存读全部实测通过。

## 2. 卡点：Windows 侧 MI_02 没有“USB 设备接口”注册

现象：

```
Info : esp_usb_jtag: VID set to 0x303a and PID to 0x1001
Error: libusb_open() failed with LIBUSB_ERROR_NOT_FOUND
Error: esp_usb_jtag: could not find or open device!
```

诊断（两条互相印证）：

1. 设备栈本身正常：`USB\VID_303A&PID_1001` 是 `usbccgp` 父设备，`&MI_00` 绑 `usbser`（COM9），
   `&MI_02` 绑 `WINUSB`（`winusb.inf`）；
2. 但 `HKLM\SYSTEM\CurrentControlSet\Control\DeviceClasses\{a5dcbf10-6530-11d2-901f-00c04fb951ed}`
   下**只有父节点** `##?#USB#VID_303A&PID_1001#<serial>#...`，没有 `&MI_02` 的子实例 →
   libusb 只能枚举到一个 `usbccgp` 节点，`libusb_open()` 必然 `NOT_FOUND`。
   （对照：可用的 `046D:C077`、`1A86:55D3` 都在该 GUID 下有实例。）

修复（等价于 Zadig 装 WinUSB，但不动签名、可逆）：

```powershell
# 1) 给 MI_02 节点补设备接口 GUID（WinUSB 启动时读 DeviceInterfaceGUIDs 注册接口）
$dp = 'HKLM:\SYSTEM\CurrentControlSet\Enum\USB\VID_303A&PID_1001&MI_02\<instance>\Device Parameters'
New-ItemProperty -Path $dp -Name 'DeviceInterfaceGUIDs' -PropertyType MultiString `
    -Value '{A5DCBF10-6530-11D2-901F-00C04FB951ED}' -Force
# 2) 重启该节点，让 WinUSB 重新注册接口
pnputil /disable-device "USB\VID_303A&PID_1001&MI_02\<instance>"
pnputil /enable-device  "USB\VID_303A&PID_1001&MI_02\<instance>"
```

之后 `DeviceClasses` 下出现
`##?#USB#VID_303A&PID_1001&MI_02#8&1896a90e&0&0002#{a5dcbf10-...}`，libusb 立即能开。

> Zadig（`zadig-2.9.exe`）本来是标准做法，但本机网络下 `zadig.akeo.ie` 与 GitHub release
> 都取不到（4xx/代理返回页），所以用了上面这条等价路径。

## 4. 这轮踩的四个坑（都记进 HANDOVER §10.3）

1. **`detach` 前必须让核跑起来**：gdb 里 `monitor halt` 之后直接 `detach`，核停在 halt，
   串口不再应答、`mx.dl` 也收不到，板子看起来“死”了。收尾要 `monitor reset run` 再 `detach`
   （或 openocd 侧 `-c "init" -c "reset run"`，但那一步在本机实测仍会停在 halt）。
2. **`esptool --after hard_reset` 无效**：它靠 RTS 拉 EN，而 RTS 没接（D16）→ 从 ROM 下载模式
   烧完芯片仍停在下载模式（UART0 不答文本命令、USB 只有 `303A:1001` CDC）。正确收尾：
   JTAG `monitor reset run`，或先让应用起来再走 `mx.dl`。
3. **CH343 会挂死**：多次开合 + JTAG 会话后，COM3 还在但完全没有数据。
   `pnputil /restart-device "USB\VID_1A86&PID_55D3\..."` 立刻恢复（同类问题见 D16）。
4. **烧录 header 写 2MB**：芯片 4MB，bootloader 打
   `Detected size(4096k) larger than the size in the binary image header(2048k)`。
   不影响运行（分区都在 2MB 内），后续可改 `--flash_size detect` 消警告。
